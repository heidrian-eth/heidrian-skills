# §P Principle index, calibration and tensions

Part of the art-movements-ux skill (SKILL.md refers to it as §P). Used in Stages 2 and 3 (mood board and kit) only, never while building a screen in Stage 4.

## P. Principle index: UI problems → who solved them

Used in Stage 2 (mood board) only, never while building a screen. Find the product's problem, read across movements, open the reference files. Each line is a principle; the artist names say where to look, not what to imitate. Lines within a problem often disagree. That is the point: pick by case, once, for the whole product.

### P.1 Problems

**One thing must win the first glance**
- Two sizes only, far apart, both hung from one axis. *Müller-Brockmann, Bayer, Scher*
- Isolate instead of enlarging: surround it with nothing. *Hara, Ruder, Sejima*
- Invert scale: a huge quiet form whose gap holds the tiny real subject. *Hokusai*
- Step value and chroma inward so the core is the extreme. *Albers, Turrell (rings)*
- One aperture in one field; the edge is a value step, not a border. *Turrell, Ando*
- Put the key figure inside the only coloured region. *Bayer, Crouwel*
- Cut one opening off-centre in a closed convex mass and put the live content inside, a value step away and quieter; a hole belongs to its object where a badge competes with it. *Hepworth*

**Many equal things, no hero**
- Same envelope, different interior. *Judd*
- A field of rooms with unequal proportions and equal weight; several peer entry points. *Sejima*
- Show every valid variant, sorted on one labelled axis. *LeWitt*
- One unit, many states: ground + form + colour index. *Vasarely, Stepanova, Le Parc, Gerstner*
- Run one rule on many seeds and show 4–8 kin side by side; or mirror the slots and not the content, with an integer count per body (3, 4, 6…) carrying the category. *Nervous System, Haeckel*

**Urgent without alarm**
- Scarcity: one small saturated mark in an otherwise achromatic field. *Klee, Malevich, Mondrian*
- Let a faint, slow field tint accompany a labelled state (never replace the label or icon). *Turrell, Sejima*
- The signal is a light that spills onto its neighbours. *Barragán, Flavin*
- Put the signal on the route the user is already walking. *Aalto*
- Turn a border into the signal instead of adding an object. *Mondrian (Boogie lanes), Hoffmann (gilt edge)*
- Make the *kind* of urgency legible by form: shape–meaning pairs, heavy vs feathered arrows. *Kandinsky, Klee*
- Darken or mute everything else. *Ando, Wright, Bayer*

**Trust, stability, seriousness**
- A heavy base: the darkest plane sits lowest. *Le Corbusier, Wright (hearth), Tanaka (black anchor)*
- Live data in a fixed slot so the layout never reflows. *Hofmann*
- Show the structure and its joints. *Crouwel, Ando, Mies, Wright*
- One family, one size; hierarchy by position and weight. *Crouwel, Ruder*
- Spend richness on exactly one surface. *Mies, Mackintosh*
- Print the rule that produced the screen. *LeWitt, Gerstner*
- Few states, plainly different. *Mies (closed, half, open)*

**Density: much data, still legible**
- Several column systems on one field, meeting only at shared lines. *Gerstner*
- Labels flush against an axis, values flush from it. *Müller-Brockmann*
- Meaning by step index on an ordered ramp, not by hue names. *Gerstner, Vasarely, Le Parc*
- Metadata light and tight so it reads as a grey plane. *Ruder*
- Compress toward the focus, reopen beyond it; or a lens. *Riley, Vasarely*
- A mass from afar, strands up close (semantic zoom). *Soto, Agnes Martin*
- Size by importance in a typographic map. *Scher*
- Rhythm from interval, with lines of one weight. *Mondrian, Judd*
- Pack to 50–73% with one constant gutter; double the count per ring so cells keep their size; chroma only on what is live (≤6%), with a label. *Haeckel*

**Where am I in a sequence (progress)**
- One continuous line that walks between the steps. *Klee*
- A coloured route on the floor. *Aalto*
- An always-visible index at the edge. *Lissitzky*
- Cells that fill in order; a band sequence that advances. *Hoffmann, Cruz-Diez*
- Number the series ("07/14"). *Le Parc, LeWitt*
- A stated progression in which solids grow as gaps shrink. *Judd*
- A promenade or ramp: the path itself is the layout. *Le Corbusier, Wright*
- Keep the item constant and grow the interval geometrically (×1.5–3 per step) from the newest end; crop the old end at the frame and keep the head whole. *Blossfeldt*

**Arriving and crossing between contexts**
- Compress, then release. *Wright, Barragán*
- A void, a pause or a bare field before the content. *Ando, Hara, Turrell*
- A small coloured opening that previews the next room. *Barragán*
- Change the material (transparent → opaque) instead of moving the object. *Moholy-Nagy*
- Give each destination its own title spread or register. *Lissitzky, Mackintosh*

**Empty state, invitation**
- Emptiness as a vessel; name the container by what it is. *Hara*
- Show the absence in the structure: a lattice with cells knocked out. *Hofmann*
- A silhouette of what will be here. *Moholy-Nagy (photogram)*
- One small off-centre mark in a large field. *Malevich, Hokusai (sketch in a frame)*

**Feedback on hover, press, select**
- Change the medium, not the elevation: value order, added light, width axis, transparency. *Albers, Le Corbusier, Judd, Ruder, Riley, Sejima*
- Invert figure and ground. *Vasarely, Stepanova*
- Resize the tracks so the selection takes space from its neighbours. *Mondrian*
- Recolour a whole plane or fill a whole cell. *Barragán, Tanaka, Crouwel*
- A mark beside the thing, not a pill around it. *Hofmann (dot), Ruder (grey step)*

**Grouping without boxes**
- Gap equal to the element. *Judd, van der Leck*
- A value step between two flat fills. *Turrell, Sejima, Albers*
- Posts, brackets or rules on one side only. *Mackintosh, Lissitzky, Hofmann (L-rule), Wright (horizontals only)*
- A change in pattern or text density. *Klimt, van der Leck, Stepanova (bands)*
- Terraces: indent plus a small tone shift. *Aalto*
- Tension a region between its anchors with edges that sag inward by about a tenth of the span; separate touching units by a rim one value step off, not by a gap. *Frei Otto, Blossfeldt*

**Depth and layering without shadows**
- Flat planes that overlap and never share an edge. *Rietveld, Popova, Malevich*
- An overlap that makes a third tone. *Moholy-Nagy, Kandinsky, Huszár*
- Emitted light. *Flavin, Barragán*
- Two systems in friction: upright content over a tilted or moving field. *van Doesburg, Soto, Cruz-Diez, Greiman*

**Delight and play that stay adult**
- A closed set of parts the user may break and rebuild safely. *Le Parc, Vasarely*
- One ordinary control made slightly unfamiliar. *Hara*
- One figure with a personality on a strict grid; one free curve where the task is densest. *Sottsass, Aalto*
- Seeded per person, or tied to the hour. *Gaudí, LeWitt, Ando, Turrell*
- A gesture with a held moment in it. *Hokusai (the crest)*

**Identity with very little surface**
- Freeze one constant across a series and vary everything else. *Crouwel*
- Build the mark from the system's own module. *Huszár, Crouwel, Vasarely*
- Stand the mark on the content, not in a corner. *Hara*
- An emblem + stripe + colour "uniform". *Stepanova*
- Ornament only at nodes. *Mackintosh, Mucha, Hoffmann*

**Live and changing data**
- Lanes in which chips tick. *Mondrian (Boogie)*
- A fixed window for the changing part. *Hofmann*
- Change bound to the user's own movement (scroll, pointer), not to a timer. *Cruz-Diez, Soto*
- A travelling wave through a constant structure. *Hofmann, Riley*
- Fix 3–7 anchors and relax everything else as one net; on any change re-solve and move every node a little (critically damped, no overshoot). *Frei Otto*

**Comparing and choosing**
- Parallel columns of honest, unequal length. *Ruder*
- The full matrix on one sorted axis. *LeWitt*
- One object in several framings. *Hokusai*
- A parameter box: one selection per row. *Gerstner*

**Destructive or irreversible acts**
- One "opponent" marked by black, not by more red. *Rodchenko*
- Weight and direction of the mark tell forward from final. *Klee*
- Make undoing visible so breaking is safe. *Le Parc*

**Posture, reach, place of use**
- Design from the body's real position: actions where the thumb is, calm where the eye rests. *Aalto, Gaudí*
- Sticky regions hold one or two glanceable things. *Bayer*
- Light from above; nothing glares. *Aalto, Ando*

**Calm over long sessions**
- Most of the surface is ground (see P.2). *Malevich, van der Leck, Ruder, Hara, Turrell*
- Washes of equal lightness; low-chroma tint instead of chrome. *Agnes Martin, Sejima*
- Ambient change slower than noticing. *Turrell*
- Focus by dimming the surroundings. *Ando, Wright*

### P.2 Calibration: what the measurements agree on

These are ranges from the measured works, pooled across unrelated artists. Use them to set the kit's budgets and tokens in Stage 3. Outside a range the effect usually changes kind; do that on purpose or not at all.

| Quantity | Range | Measured in |
|---|---|---|
| A **signal** colour (reads as a mark) | ≤1% for a point; 1–8% for the main accent; all saturated colour ≤~13% | Klee (sun ≤1%), Malevich (bar ≤1%), Rietveld (yellow ≈1%), van der Leck (yellow ≤3%), Kandinsky (yellow ≤5%), Ando (light 5–7%), Barragán (5–10%), Mondrian (1–8%, total ≤13%) |
| Colour as a **region** (reads as a place, not a mark) | one contiguous plane, ~20% up to ~90% | Bayer (≤20%), Hokusai (~19–21%), van Doesburg (45–50%), Crouwel (89%) |
| Saturation vs area | the most saturated plane is the smallest; the extreme sits at the core | Barragán, Albers |
| **Quiet ground** in a calm composition | 60–85% of the surface | Ruder (60%), Kandinsky, Malevich (65–75%), van der Leck (64–84%), Turrell (≥75%), Moholy-Nagy (≈80%), Hara (60–90%) |
| Adjacent surfaces told apart **without a border** | 3–5 L apart (1–3 L reads as "the same white, alive") | Albers (3–5), Sejima (~5), Turrell (4–8%), Mondrian (1–3) |
| **Line weights** | two only, far apart: a hairline (~0.2–0.35% of width) and a bar (~1–1.5%) | Kandinsky, Sejima, Mondrian |
| **Scale jump** that reads as intent | ≥1:6; extremes 1:13 (type), subject at 0.5–5% of the frame | Müller-Brockmann, Scher, Hokusai, Hara |
| **Dominant area** | 22–55%, pushed off-centre | Mondrian (22–53%), Barragán (35–45%) |
| **Splits** | either a hard ~50/50 or clearly unequal (45/55, 1:3, 72/28); never "almost" | Crouwel, Hara, Mies, Barragán, Hokusai |
| Hues sharing a field | several hues can coexist if none exceeds ~8% and a neutral anchors a third or more | Tanaka |
| **Motion by material** | mechanism: stepped, <200–320ms; light: 600–1400ms; ambient: 30s+; stagger 70–120ms | Stepanova, Rietveld; Barragán, Ando, Hara; Turrell; Tanaka, Judd, Albers |

When an entry is corrected, update this table. When you use a value, recalibrate for the device and viewing distance, and say so in the trace.

### P.3 Tensions worth keeping

Opposed principles from the library. Do not average them. Give each pole a territory defined by **role** (what kind of thing it is), never by screen or section, so the same split holds everywhere in the product.

| Tension | Poles | Typical resolution |
|---|---|---|
| Scarcity ↔ colour as place | Klee, Malevich ↔ Crouwel, van Doesburg | a region for *where you are*, a point for *what needs you* |
| Void ↔ density | Hara, Ruder ↔ Gerstner, Scher, Klimt | void around the one figure, density in the reference matter |
| Hard jump ↔ no hierarchy | Müller-Brockmann ↔ Sejima, Judd | one jump for the single key figure, flat equality for everything else |
| Fixed slot ↔ room that reconfigures | Hofmann ↔ Rietveld, Mondrian | system news in fixed slots; the user's own actions may move walls |
| Show structure ↔ thinnest structure | Crouwel, Ando ↔ Sejima, Turrell | structure visible where the user builds or edits; dissolved where they read |
| Mechanism ↔ light | Stepanova, Hoffmann ↔ Turrell, Barragán | steps for what the user does; slow light for what the system reports |
| Order ↔ one free element | Aalto, Müller-Brockmann, Tanaka | the free element sits exactly where the main task is |
| System ↔ the hand | LeWitt, Gerstner ↔ Agnes Martin, Klee | rule-generated layout, one hand-made or per-user detail |
