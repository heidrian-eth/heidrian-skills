# heidrian-skills

Agent skills for Claude Code and compatible agents.

## Skills

| Skill | Description |
|---|---|
| [art-movements-ux](art-movements-ux/SKILL.md) | Non-generic, art-informed UI/UX: generate variants in the manner of 10 art/architecture movements (50 artists), then synthesize. |

## Install

Copy a skill folder into `~/.claude/skills/` (or a project's `.claude/skills/`).
